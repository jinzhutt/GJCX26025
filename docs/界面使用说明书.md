# 一体式新型耐压设备（PressureTestApp）界面使用说明书

适用版本：v2.0.0-stage3（`.NET 8 + Avalonia 11`）  
适用平台：Windows 10/11、统信 UoS V20（项目目标平台）

---

## 1. 软件启动流程（从开机到进入主界面）

### 1.1 启动页（加载中）
启动程序后首先进入“加载中”窗口，包含：
- **进度条**：显示启动流程进度。
- **状态文字**：依次显示“加载配置 / 连接数据库 / 检测网络 / 启动完成”等。

启动完成后会自动跳转到登录窗口。

### 1.2 登录页
登录窗口右侧为登录表单、左侧为产品介绍卡片。

- **工号**：输入工号（账号）。
- **密码**：输入密码。
- **记住密码**：勾选后下次可自动填充（取决于配置/实现）。
- **登 录**：执行登录。
- **设备认证 / 重新认证**：当前为入口按钮（界面存在，业务逻辑以实际版本为准）。
- **人脸识别**：显示“待接入”，当前不可用。

默认账号（开发/演示环境）：
- **工号**：`admin`
- **密码**：`admin`

常见提示：
- **错误提示**：表单下方会以红字显示 `ErrorMessage`（例如账号/密码错误）。

## 2. 主界面总览（试验主界面）

登录成功后进入主窗口 `试验主界面`。整体布局为：
- **顶部标题栏**：应用名、运行状态、时钟、最小化/最大化/关闭按钮。
- **左侧导航栏**：试验主界面、历史报表、设备检查、硬件校准、串口仪器、用户管理、系统日志、退出系统。
- **右侧内容区**：根据导航项显示不同内容（默认显示试验主界面）。
- **底部状态栏**：当前登录工号、PLC 状态、仿真模式、网络错误提示等。

### 2.1 顶部标题栏
- **拖拽窗口**：在标题栏按住鼠标左键可拖动窗口。
- **双击标题栏**：在最大化/普通窗口之间切换。
- **最小化 / 最大化 / 关闭**：右上角三个按钮。

### 2.2 左侧导航栏（入口说明）
- **试验主界面**：耐压试验的主要操作区（默认）。
- **历史报表**：入口存在，当前以日志记录/占位为主（以实际版本为准）。
- **设备检查**：进入“设备检查”面板（计数器归零等）。
- **硬件校准**：进入“硬件校准”面板（输入/输出校准参数）。
- **串口仪器**：入口存在，当前以日志记录/占位为主（以实际版本为准）。
- **用户管理**：进入“用户管理/数据设置”面板（用户、指纹、型号、参数、检查人员、保护参数）。
- **系统日志**：入口存在，当前以日志记录/占位为主（以实际版本为准）。
- **退出系统**：退出当前账号并返回登录页。

## 3. 工作模式说明（在线 / 离线 / Excel）

试验主界面左侧包含模式切换区：
- **在线模式**：任务来源为接口/在线任务（按项目 README 描述）。
- **离线模式**：任务来源为本地产品型号库；界面会显示“4 路回路卡片”等离线相关内容（以当前版本显示为准）。
- **Excel**：从 Excel 模板导入任务；导入后顶部会出现 Excel 横幅（文件名、任务数、重新导入按钮）。

### 3.1 Excel 横幅（仅 Excel 模式且已加载文件）
当已导入 Excel 后，内容区顶部会显示“已加载 Excel：xxx · 共 N 条任务”，并提供：
- **查看任务列表**：入口按钮（以实际版本为准）。
- **重新导入**：打开文件选择器，重新选择 `*.xlsx`/`*.xls` 文件导入。

## 4. 试验主界面（核心操作区）

试验主界面主要由“左侧信息与按钮区 + 中间曲线/信号/页签 + 右侧模拟量输出/任务管理”组成。

### 4.1 信息录入（车型选择）
在“信息录入”卡片内：
- **车型型号**：文本框显示已选车型信息（通常由“车型选择…”带入）。
- **车型车**：文本框显示已选车型信息（通常由“车型选择…”带入）。
- **车型选择…**：弹出“车型选择”窗口，从列表中选择后自动回填。

### 4.2 参数设定（回路 1~4）
“参数设定”区域为 2×2 布局：
- **回路 1~4 单选**：选择当前要操作/关注的回路。
- **回路 1~4 输入框**：用于填写回路预设文本（具体含义以业务定义为准）。

说明：
- 当参数输入框获得/失去焦点且内容发生变化时，系统会在“试验信息过程”日志中记录“修改参数「xxx」”。

### 4.3 试验信息过程（过程日志）
“试验信息过程”区域会滚动显示过程日志（自动滚动到最新一行）。
常见记录场景：
- 修改参数（如回路/车型输入等）
- 使用“任务查看/任务上传/绝缘测试/重新导入 Excel/退出系统”等入口

### 4.4 语言播报
“语言播报”区域显示当前语音播报文本（若后续接入语音模块，此处用于提示操作与状态）。

### 4.5 试验时间与状态
左侧还有：
- **剩余秒数**：以大号数字显示 `RemainSeconds`。
- **状态摘要**：显示实时指标行与 `StatusText`（如运行/就绪等）。

### 4.6 开始/结束试验
左侧底部两个大按钮：
- **开始试验**
- **结束试验**

在 Excel 模式下，还会额外显示：
- **重新导入 Excel**（与顶部横幅一致）

## 5. 中间区域（曲线 / 信号 / 右侧页签）

### 5.1 右侧页签（工艺界面 / 摄像头一 / 报表界面）
在中间区域顶部可切换：
- **工艺界面**：显示检测值、检测信号、耐压曲线等核心试验数据。
- **摄像头一**：显示“摄像头预览（待接入设备）”，并提供“开启摄像头/退出摄像头”按钮（当前为预留）。
- **报表界面**：表格区域预留；右侧提供“上翻/下翻、页码微调、保存报表、打印报表”等按钮（以实际版本为准）。

### 5.2 工艺界面：检测值
以卡片形式显示（示例）：
- 高压输出检测(V)
- 泄漏电流检测(mA)
- 厂房电压检测(V)
- 环境温度(℃)
- 环境湿度(%)

### 5.3 工艺界面：检测信号（信号灯）
“检测信号”区显示两排信号灯与文字（颜色随状态变化）。常见项包括：
- 接地保护、电脑控制、电铃信号、升压器输入过流、保护电流、耐压时间、操作台柜门
- 调压器低限位、调压器高限位、主接触器合闸、自动放电动作
- 计时开始、从接触器合闸、启动信号、升压信号、降压信号、停止、复位、复位完成、放电完成

### 5.4 耐压曲线
“耐压曲线”区域显示电压/泄漏电流随时间变化曲线（图例分别为“电压(kV)”与“泄漏电流(mA)”）。

## 6. 右侧区域（模拟量输出 / 任务管理 / 打印）

### 6.1 模拟量输出（数值设定）
包含三项：
- **试验时间设定(S)**：数值输入（范围 1~3600）。
- **保护电流(mA)**：数值输入（范围 0~500，支持 1 位小数）。
- **自定义电压设定(V)**：数值输入（范围 0~15000，支持 2 位小数）。

操作方式：
- 点击数值输入区域会弹出“数值设定”对话框，输入后点击“确定”生效，“取消”不修改。

### 6.2 任务管理
从上到下四个按钮：
- **任务下载**：当前版本仅记录点击日志（弹窗界面已移除）。
- **任务查看**：打开“任务查看”窗口（筛选 + 表格）。
- **任务上传**：打开“任务回传”窗口（与任务查看共用界面，底部出现“一键数据回传/界面退出”）。
- **绝缘测试**：打开“绝缘电阻测试仪”窗口；若未检测到可用串口，会先弹出“未检测到可用串口！”提示。

### 6.3 打印报表
右侧底部提供“打印报表”按钮（以实际版本为准）。

## 7. 任务查看 / 任务上传窗口（TaskViewWindow）

该窗口用于任务列表展示与操作；标题会随模式变化（例如“任务查看/任务回传”等）。

### 7.1 筛选区
筛选项与按钮：
- **车型编码**：下拉选择（`--请选择--`）。
- **配属列号 / 配属辆号**：下拉选择（界面标签以窗口实际显示为准）。
- **车列号**：下拉选择。
- **搜索**：执行筛选查询并刷新表格结果。

### 7.2 结果表格
表格列包含（节选）：
- 车型编码、配属列号、配属辆号、车列号、明细ID
- 施工任务ID、耐压子任务ID、步骤名称、操作区域、操作内容
- 环境温度/湿度、实际施加电压、试验结果值、备注
- 操作人姓名/工号、操作时间、自检/互检/质检信息等

表格操作：
- **表头勾选**：全选/取消全选。
- **行勾选**：选择要操作的任务行（用于回传/重做等）。
- **右侧“操作”列**：每行提供操作按钮（文案由 ViewModel 决定，常见为“任务重做/选择/回传”等）。
- **底部横向滚动条**：用于横向拖动查看更多列（表格内部横向滚动条被隐藏，统一使用底部横条）。

### 7.3 底部操作（仅任务上传/回传模式显示）
当窗口处于回传模式时，底部出现两个按钮：
- **一键数据回传**：对已勾选任务执行回传。
- **界面退出**：关闭窗口返回主界面。

- **▲ / ▼**：移动当前选中行。

## 9. 数值设定对话框（NumericEditDialogWindow）

入口：
- 主界面右侧“模拟量输出”区域点击数值项（试验时间/保护电流/自定义电压）。

使用方法：
- 在输入框中输入数值（支持回车）。
- 点击 **确定** 保存；点击 **取消** 放弃。
- 若超出允许范围，会在输入框下方显示红色错误提示。

快捷键：
- **Enter**：等同“确定”（默认按钮）。

## 10. 绝缘电阻测试仪（InsulationResistanceTestWindow）

入口：
- 主界面右侧“任务管理”中点击 **绝缘测试**。

串口提示：
- 若系统未检测到可用串口，会先弹出提示框“未检测到可用串口！”；点击“确定”继续进入测试仪窗口。

### 10.1 串口连接
- **串口号**：下拉选择串口。
- **连接 / 断开**：连接或断开串口。
- **连接状态**：显示“未连接/已连接”。

### 10.2 绝缘电阻测试参数
可设置：
- **测试电压 DC(V)**：1~10000
- **测试时间(S)**：0.1~7200
- **电阻下限(MΩ)**：0~999999

执行：
- **开始绝缘电阻测试**
- **停止绝缘电阻测试**

### 10.3 测试结果区
- **倒计时**：显示测试倒计时。
- **绝缘测试状态 / 测试值 / 测试结果**：以文本框展示（当前允许编辑，便于调试/录入；以实际版本为准）。

## 11. 设备检查（DeviceInspectionView）

入口：
- 左侧导航栏点击 **设备检查**

界面内容：
- 以 4 列网格展示多个**计数器**（如某些动作次数、报警次数等，具体项由数据源决定）。

操作：
- 每个计数器卡片右侧有 **归零** 按钮：将该计数器清零。
- 右上角 **✕**：返回试验主界面。

---

## 12. 硬件校准（HardwareCalibrationView）

入口：
- 左侧导航栏点击 **硬件校准**

界面结构：
- 左侧 **输入检测**：多行通道（按列表展示）。
- 右侧 **输出检测**：单个输出通道（固定一行）。

每行字段：
- **测定值 / 零点值 / 增益值**
- **确定**：提交本行校准参数。
- **重置**：恢复/清空本行校准参数（以实际实现为准）。

公式提示：
- 计算公式：**测定值 = 工程值 × 增益值 − 零点值**

右上角 **✕**：返回试验主界面。

## 15. 常见操作流程（快速上手）

### 15.1 快速开始一次试验（建议流程）
- 登录进入主界面。
- 在“信息录入”点击 **车型选择…**，选择车型并确认回填。
- 根据需要切换工作模式（在线/离线/Excel）。
  - Excel：点击 **重新导入** 选择 Excel 模板文件。
- 在“参数设定”选择回路并填写必要参数。
- 在右侧“模拟量输出”设置试验时间/保护电流/电压（点击弹窗输入，按“确定”保存）。
- 点击 **开始试验** 开始；必要时点击 **结束试验** 停止。
- 如需回传：点击 **任务上传** 打开回传窗口，勾选任务后点击 **一键数据回传**。

### 15.2 绝缘电阻测试
- 点击 **绝缘测试**。
- 选择串口并点击 **连接**（无串口时会先提示）。
- 设置测试参数，点击 **开始绝缘电阻测试**。
- 观察结果与倒计时，完成后点击 **停止绝缘电阻测试**，再断开串口。

## 16. 退出登录 / 退出系统

在左侧导航点击 **退出系统**：
- 会记录操作日志；
- 退出当前主界面；
- 返回到登录窗口。
